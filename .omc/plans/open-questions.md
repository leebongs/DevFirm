- [x] **O-5. 비개발자 콘텐츠 수정 → 개발자 배포 (CMS 미도입)**
  ADR-003 기본값 확정. 전 카피를 `content/*.ts` 타입드 모듈로 유지, CMS는 Phase 6 재검토.

## 시각 자산 배치 계획 (visual-placement-plan) - 2026-08-01

- [ ] **Q-1. `staffing.difference` 좌변 4문장 카피 승인** — 프리랜서 직접 계약 시 벌어지는 일을 명시적으로 서술하는 신규 카피다. 경쟁 대안을 지목하는 셈이라 톤·수위에 사용자 판단이 필요하다.
- [ ] **Q-2. `/contact` 지도를 약도 SVG 로 되돌릴 것인가** — image-plan §10 의 "실제 지도 임베드" 결정을 이 라우트에서만 뒤집는다. 근거는 실측(Google 서드파티 392KB, lazy 가 작동하지 않음)이지만 결정은 사용자 몫이다.
- [ ] **Q-3. `illustrations.home` 폐기 승인** — 홈이 사진+영상 히어로로 바뀌며 고아가 된 620×520 자산. 파일과 레지스트리 항목 삭제 여부.
- [ ] **Q-4. `/workspace` 시설 실촬영 계획 유무** — 있다면 신규 생성 예산을 `/academy` 사진에서 그쪽으로 옮기는 편이 가치가 크다. 없다면 현재 일러스트 3점을 유지한다(방문 가능한 실물 공간을 생성 이미지로 대체하지 않는다).
- [ ] **Q-5. Lighthouse 측정 URL 확대 여부** — 이 계획이 바꾸는 페이지 중 LH 가 보는 것은 `/solutions`·`/contact` 뿐이다. `/services/staffing`·`/academy` 추가는 회귀 감지에 필요하나, 두 페이지가 전 카테고리 ≥95 임을 로컬 확인한 뒤에만 커밋해야 한다.
