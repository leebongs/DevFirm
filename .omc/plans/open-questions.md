- [x] **O-1. 폼 제출 처리 → Resend + `mailto:` 폴백**

- [x] **O-2. 이미지 자산 → 기존 재사용 + 저채도 오버레이**
  cmnyx.com 기존 이미지를 그대로 쓰되 흑백/저채도 오버레이로 톤 통일. 히어로 LCP는 텍스트라 이미지 의존도 낮음. 원본이 저해상도인 항목은 Phase 2에서 목록화해 타이포 중심 대체 블록으로 전환한다.

- [x] **O-3. 다크모드 → 미지원, Phase 6 연기**

- [x] **O-4. 지도 → 정적 이미지 + 외부 링크**
  외부 지도 SDK 미도입. `rel="noopener"` 외부 링크로 카카오맵 연결. A7(Perf ≥ 95)·CSP 리스크 제거.

- [x] **O-5. 비개발자 콘텐츠 수정 → 개발자 배포 (CMS 미도입)**
  ADR-003 기본값 확정. 전 카피를 `content/*.ts` 타입드 모듈로 유지, CMS는 Phase 6 재검토.

  신규 도메인이 정규(canonical). 계획 변경 사항은 아래 참조.

| 영역 | 추가/변경 |

| Phase 5 | 도메인 확보·DNS·Vercel 2도메인 연결·검색콘솔 주소변경 작업 추가 |
