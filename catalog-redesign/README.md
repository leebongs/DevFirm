# DocASI 스토리텔링 카탈로그

원본 `catalog.pdf`의 내용을 바탕으로 재구성한 A4 세로 8페이지 카탈로그입니다.

- 편집 원본: `catalog.html`, `catalog.css`
- 출력 스크립트: `node print.mjs`
- 최종 PDF: `out/DocASI-catalog-storytelling.pdf`
- 페이지 미리보기: `out/page-01.png` ~ `out/page-08.png`
- 전체 대조 시트: `out/contact-sheet.png`

## 편집 방향

1. 일지 한 장에서 시작해 담당자 행동으로 이어지는 이야기 구조
2. 원본의 실제 수치(5분, 이슈 6건, 고위험 2건)를 시각화
3. 밝은 스카이·민트·코랄·옐로 팔레트와 네이비 신뢰색 조합
4. 제품 화면, 3층 기준, 데이터 경계, 당일 도입을 도표 중심으로 재편
5. LLM API 전송 범위와 법적 고지를 명확히 보존

## 생성 이미지 프롬프트 요약

- 표지: 밝은 건설 현장 사무소에서 담당자가 일지를 검토하고 문서가 점검 카드로 바뀌는 프리미엄 편집 일러스트
- 문제 장면: 일지 한 장 주변에 여섯 개의 점검 신호가 나타나는 밝은 B2B 편집 일러스트

두 이미지는 내장 이미지 생성 도구로 제작했고 `assets/`에 저장했습니다.
