중요 고지

분석 시 문서 본문과 가이드라인 발췌가 LLM 벤더 API로 전송되며 벤더의 API 데이터 정책이 적용됩니다. 분석 결과는 검토 지원 정보이며 법적 확정 판단이 아닙니다. 최종 판단은 담당자가 합니다.
